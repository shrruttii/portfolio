# Shruti — Portfolio

A distinct student portfolio with a playful collage hero, project shelf, and bright classroom playground. Built with plain HTML, CSS, and JavaScript.

Open `index.html` in a modern browser. The prompt builder and FAQ work locally. The weather lookup uses Open-Meteo and requires an internet connection, but no client-side API key.

The project summaries are adapted from the supplied portfolio materials. Confirm personal details and add real repository links before publishing.

Additional features include project category filters, expandable project notes, and a current-learning focus section.
